# “漫漫”人生路，与爱携手行

> 更新时间：2026-09-17 (UTC+8)

点击上方“蓝色字体” 可以订阅哦！
      有这么一个地方，寒冷与温暖交织，无奈与希望同在，如果说医院是一个生与死较量的战场，那么急诊科就是这个战场最激烈的前沿阵地。11月已进入了深秋，河池市人民医院急诊科工作节奏没有因为深秋的天气变化而打乱，急救电话放下又响起，救护车的鸣笛声与马路的喧嚣声环绕着这座城市。

       雨后初晴，明媚的阳光驱散了连日阴雨的霉气。上午十点，河池市人民急诊科接到急救电话后迅速出诊，电话里头患者的信息让出诊医生神经瞬间绷紧：十岁左右的小姑娘，衣衫褴褛，昏倒在大街上，且联系不上姑娘的家属等等一系列的信息，让出诊的医护人员感觉不妙。

        出诊的医护人员到达现场，穿过人群，看到了小姑娘，瞬间松了一口气……原来，昏倒在大街上的小姑娘小名叫漫漫，今年9岁，从小父母离异，因缺少父爱母爱的滋养，从而变得性格孤僻、自卑，“昏迷”只是为了引起大家的关注。医护人员已经记不清这是她今年第几次由急诊科救护车接回来了，以往每次接回医院，漫漫都是吃完医护人员提供的食物后，就悄悄地离开了。漫漫从不与人对话，目无表情，每次当医护人员从繁忙的工作中回过神来的时候，已经找不到她的身影了。

漫漫接入急诊科时的状态

   “慢慢喜欢你

    慢慢的亲密

    慢慢聊自己

    慢慢和你走在一起”

       也许真的像歌词里唱的，这一次接诊接触，漫漫开始与熟悉的出诊兰医生微笑了，也开口叫“兰姐姐”了，回到急诊科里兰医生用自己的行动温暖漫漫得到的第一次回应，让人很是欣慰，也感觉很有成就感，急诊科的所有医护人员都为漫漫性格的转变感到开心。

科室人员为漫漫准备的衣物

      这一次漫漫到急诊科后，没有像以往一样悄悄离开，而是很安静地在科室呆着，似乎在等待着什么。待到下班时间，漫漫主动跟在“兰姐姐”身后，两人很默契地到了值班室。

        原来事先兰医生就有交代漫漫要在这里安静的坐着，并叫休息的同事帮送来小朋友的换洗衣物，待她忙完急诊科的工作后就带漫漫去换洗。因是熟悉的兰姐姐，这一次漫漫真的在安静的等兰医生下班，于是就出现了上面的温馨画面。

      爱有温度，且真实。不管之前你遇到什么，经历了什么，愿在未来的日子里，你成为自己心中的太阳，河池市人民医院急诊科的“代班妈妈”和“代班爸爸”一直为你守护。这，就是我们急诊医护人员，虽然岁月里经受了太多的不理解，可不变的信念依然在我们身上展现着。不求C位出场，但求无愧于心。
