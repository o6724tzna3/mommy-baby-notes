# 39岁大龄女性用微刺激方案促排的全部流程是怎样的？

> 更新时间：2026-09-10 (UTC+8)

39岁，之前有宫腔粘连的情况所以一直不能正常怀孕，今年就还是想试试看，能不能怀孕，所以去做了试管婴儿。因为我年级比较大了医生就给我安排的是用微刺激方案促排，这样对我的卵巢伤害小一些。我想提前了解下该方案的促排流程，就想问问39岁大龄女性用微刺激方案促排的全部流程是怎样的？

39岁用微刺激方案促排与其他方案流程其实是差不多的，只是微刺激方案药物用量会少很多。该方案一般会在月经来潮的第3-5天开始促排，等到卵泡生长到18mm左右时，就给注射绒毛膜促性腺激素夜针，然后等待36小时后即可取卵。微刺激方案促排天数并不长，整个的用药流程只要8-10天左右即可完成，相较于大部分的方案会短一些，用药也会比较简单一些。
微刺激方案是通过应用单用口服促排卵药物或小剂量促排卵针剂，或者联合使用两者等小剂量促排卵药物促使卵泡生长方法进行促排。一般微刺激方案使用的针剂剂量一般每天不超过150u。
微刺激方案是目前在试管婴儿期间使用比较频繁的一种促排方案，在治疗期间，它对女性的卵巢刺激更小，同时用药量也少，是很多患者都接受的一种促排方案。其促排流程如下：

- 1. 在月经第二天开始监测卵泡和检查性激素六项，检查结果达标则会在月经第二天服用法地兰，直到收针为止；
- 2. 在月经来潮第3~5天就可以开始促排卵治疗；
- 3. 疗程需要8~10天左右，等到卵泡的直径生长到17-18mm后使用绒促性素(HCG)夜针；
- 4. 在使用夜针后36小时就可以取卵了。
相比于其他常规方案而言，微刺激方案促排的时间较短，而且获得的卵子数量也较少，一般有1-6个为多见。但微刺激方案卵子质量却不见得比其他方案差。
