# 吃猪肝红枣粥的好处

> 更新时间：2026-09-15 (UTC+8)

吃猪肝红枣粥的好处

猪肝和红枣是两种对人体有滋补作用的食物，而在平日里，人们也会将二者搭配制作成猪肝红枣粥进行食用，那么，吃猪肝红枣粥的有什么好处呢?

**目录**

1**猪肝红枣粥的做法**

　　主料：糯米(紫)100克

　　辅料：猪肝50克,枣(干)50克

　　调料：白砂糖30克

　　制作方法：

　　1. 将猪肝洗净切碎;

　　2. 锅内加入豆油适量，煸炒猪肝;

　　3. 洗净红糯米，与红枣同入锅煮粥稠;

　　4. 调入已煸炒的猪肝，再煮沸10分钟;

　　5. 加白糖调味。

2**吃猪肝红枣粥的好处**

　　吃猪肝红枣粥的好处：

　　枣(干)：枣含有维生素A、C、E、P，生物素，胡萝卜素磷、钾、镁等矿物质，叶酸，泛酸，烟酸等。它有提高人体免疫力，防治骨质疏松和贫血，软化血管，安心宁神等作用。中老年人更年期骨质疏松、青少年生长发育高峰期缺钙、女性易贫血缺铁等，食用枣类食品都会有很好的食疗效果，病后体虚的人食用枣类也有很好的滋补作用。红枣适宜慢性肝炎，肝硬化之人服食，也可减少其他药物对肝脏的损害。红枣中含环磷酸腺甙，可扩张血管，增强心肌收缩力，改善心肌营养，对防治心血管疾病有一定好处。

　　猪肝：猪肝中含有丰富的维生素A、维生素B2、铁等元素，有补肝、明目、养血的功效，特别适合贫血、常在电脑前工作、爱喝酒的人食用。红枣中还含有大量的环磷酸腺苷，它能调节人体的新陈代谢，使新细胞迅速生成，老死细胞很快被消除，并能增强骨髓造血功能，增强血液中红细胞的含量。常吃红枣能增加皮肤的弹性，修补皮下组织，使皮肤变得细嫩光滑。

3**吃猪肝的禁忌**

　　一、食用过多。猪肝含有的胆固醇较高。如果一次食用过多，摄入的胆固醇就会过量，会导致动脉硬化和加重心血管疾病，因此高血压和冠心病患者应少食猪肝。

　　二、与维生素C同服。维生素C易被氧化破坏，尤其是遇到某些微量元素时氧化更为迅速。猪肝中铜元素含量较高，它可与维生素C结合，使维生素C失去原来的功能。

　　三、不排毒就食用。猪肝是猪体内最大的解毒器官，各种有毒代谢产物和饲料中的某些有毒物质，都会留在猪肝内，并经它解毒后进入肾脏，再通过小便排出体外。猪肝中含有毒素的血液是分散存于数以万计的猪肝窦中的，因此买回来的猪肝应用自来水冲洗10分钟，再放在水中浸泡30分钟，才可食用。

　　四、与酶制剂同服。常见的酶制剂有胃蛋白酶、胰酶、淀粉酶、多酶片等，猪肝中的铜可与酶蛋白质、氨基酸分子的酸性基因形成沉淀物，影响药效。因此，吃猪肝时不能服用酶制剂药类。

　　五、炒得过嫩。猪肝加热过短，不能杀死猪肝中的某些病菌和寄生虫卵，因此，吃猪肝不能炒得过嫩。

4**哪些人不能吃红枣**

　　1.吃维生素K的人。大枣如果和维生素K一起吃，维生素K就会被分解掉，疗效也就别提了。

　　2.喜欢吃葱、黄瓜、萝卜、海鲜及动物肝脏的人。这些食物中的一种如果和大枣同食，营养免谈，还可能导致中毒。

　　3.儿童。大枣黏腻，而孩子的脾胃功能弱，吃多了不易消化，还会降低他们的食欲。大枣含糖量高，容易导致孩子龋齿。

　　4.经期女性。有些女性喜欢在经期煮大枣水喝，这是不科学的。因为喝了大枣水后，月经量就会增多，不但不能补身体，反而对身体有害。经期有水肿症状的女性，吃大枣后体内生湿，只能是加重病症。

　　5.胃病患者。大枣皮硬，不好消化和吸收。胃黏膜最怕硬东西损伤，胃不好的人吃大枣要去皮。大枣能激发胃酸分泌，因此，胃酸多和易反酸者最好别吃大枣。

　　6.咳漱痰多者。吃大枣后引起生痰和生湿，容易导致病情加重。

　　7.腹胀者。吃大枣会导致胀气，因此腹胀者包括腹胀的孕妇，尽量不要吃大枣以及喝大枣水。

　　8.糖尿病人。大枣含糖量高，糖尿病人如果贪吃大枣，只能是加重病情。

　　9.习惯性便秘者。枣皮纤维含量很高，不容易消化，肠胃道不好的人，腹胀的人，习惯性便秘者一定不能多吃。

　　10.肾功能失调者和患有尿毒症的病人。尽量少吃或者不吃大枣。
