# 5种“碱性食物”，对排出尿酸有利，建议高尿酸患者要常吃

> 更新时间：2026-09-17 (UTC+8)

“医生，我患痛风有一段时间了，我听说痛风是因为尿酸高导致的，多吃碱性食物就能缓解，碱性食物还能促进尿酸排出，是这样么？”

39岁的张先生平时有事没事总是喜欢喝点酒，而且有的时候工作应酬还会喝的酩酊大醉，平时饮食上也比较喜欢海鲜，动物内脏这些食物，前段时间体检查出尿酸有一些高，本来脚踝就有些疼痛，但是张先生一直也没在意，直到体检发现尿酸高才知道原来是患上了痛风，听说碱性食物对排出尿酸有利，就想着赶紧来问问医生。

“张先生，您好，痛风确实是由高尿酸血症引起的，而碱性食物可以中和尿酸，多食用碱性食物可以缓解痛风的症状，还可以促进尿酸的排出。”

高尿酸血症对于大家来说可能有些陌生，但是说到痛风大家一定知道，而高尿酸对于痛风患者来说是必然存在的，高尿酸时刻危害着我们的健康，除了会继发痛风，还有可能诱发肾炎，肾结石，严重还会导致肾功能不全，因此对于尿酸高的患者来说，如何降尿酸，排尿酸是非常重要的。那么高尿酸血症是如何形成的呢？吃哪些食物对排出尿酸有利？让我们一起来了解一下。

高尿酸血症是如何形成的？

1. 原发性高尿酸血症

原发性高尿酸血症的主要原因是尿酸排泄减少以及尿酸生成增多这两大因素造成的，尿酸排泄减少是由于肾小球滤过率降低，导致身体里的尿酸不能完全经尿液代谢出去，从而造成高尿酸血症；而尿酸生成增多是由于嘌呤代谢异常，嘌呤物质摄入过多而导致的高尿酸血症。

2. 继发性高尿酸血症

顾名思义，继发性高尿酸血症是继发于身体其他的疾病，比如白血病，恶性肿瘤放化疗后，慢性肾病，以及抑制尿酸排泄的药物，例如呋塞米，阿司匹林等。

3. 嘌呤类食物摄入过多

经常食用含嘌呤物质高的食物也是高尿酸血症的重要原因之一，动物内脏，海鲜，这些都是嘌呤含量较高的食物，另外经常饮酒，酗酒也会导致尿酸增高。

以下5种“碱性食物”对排出尿酸有利

1. 苏打饼干和苏打水

苏打饼干和苏打水中含有碳酸氢钠这一物质，碳酸氢钠有中和尿酸的功效，因此尿酸高的患者可以适当食用一些苏打饼干，苏打水。但是不要大量的食用苏打饼干，苏打饼干中有食盐的成份，大量食用有诱发高血压的风险。

2. 猕猴桃

猕猴桃可以说是水果中的Vc之王，而且猕猴桃中还有碱性成分可以中和过高的尿酸，猕猴桃中还含有丰富的钾离子，可以促进尿酸经尿液代谢。

3. 牛奶

牛奶中还有丰富的营养物质，含有人体所需的微量元素，含有丰富的钙离子钾离子，这些微量元素对于尿酸排出也是十分有利的。

4. 西红柿

西红柿可以说是既是蔬菜也是水果，西红柿属于碱性食物，可以促进尿酸排出，而且西红柿中也是含有丰富的钾离子，可以促进尿酸代谢。

5. 鸡蛋

鸡蛋中含有丰富的蛋白质，对于尿酸高的患者来说可以多吃一些蛋白质丰富的食物，鸡蛋就是一种不错的选择，没有多余的脂肪成份，而且鸡蛋中含有维生素E对于尿酸引起的疼痛能起到缓解作用。

高尿酸血症的治疗

1. 饮食调理

对于轻度尿酸增高，并没有其他症状的患者来说，改变饮食习惯是非常重要的，减少嘌呤类物质的摄入量，戒烟戒酒，保持良好的饮食习惯可以有效的降低尿酸。

2. 碱化尿液

当患者尿酸增高异常，我们可以通过碱化尿液来降低尿酸。可以食用碳酸氢钠来中和尿酸，但是不要长时间服用，以免造成代谢性碱中毒。

3. 药物治疗

药物治疗是最有效最快速的方式，但是对于轻度的患者来说还是建议通过饮食调理来改善病情。高尿酸血症的药物治疗有很多种，因此药物治疗则需要查明原因，对因治疗，对症治疗，临床上常用的药物有增强排泄尿酸的药物如苯溴马隆，抑制尿酸合成的药物如非布司他等，具体的药物治疗需要医生根据病情来决定。

还有哪些方式可以较低尿酸？

1. 增强运动

适当的运动不仅可以增强体质，还能降低尿酸，但是对于尿酸增高并伴有痛风的患者来说，就不能通过运动来降低尿酸了，这种降尿酸的方式只适合轻度尿酸增高的患者。

2. 减肥

对于体重超标的肥胖患者来说，减轻体重可以有效的降低尿酸，而且肥胖也是诱发尿酸增高的因素之一，肥胖还会诱发其他身体疾病，因此减肥是对健康非常有好处的。

3. 多饮水

多饮水可以促进肾脏代谢，尿液排出增多，尿酸也随之代谢出去，因此多饮水也是降低尿酸的方法之一，但是切忌一次性大量饮水。

4. 避免熬夜

饮食习惯，生活习惯都是可以降低尿酸的，而熬夜也是健康的一大杀手，熬夜会导致内分泌紊乱，从而造成尿酸增高的情况，因此作息规律，避免熬夜对于降低尿酸也是十分必要的。

高尿酸血症的发生率是非常高的，而大多以无症状为主，一般都在体检中发现，但是高尿酸血症对人体健康的危害是巨大的，所以不管有无症状，我能都应该积极治疗高尿酸血症，轻度的尿酸增高可以通过饮食调理，增强运动，减轻体重来缓解，重度的高尿酸血症或者伴有痛风情况的发生则需要用药治疗，对于痛风急性发作期的患者可以采用非甾体抗炎药来缓解疼痛，必要时可以使用糖皮质激素.

相信大家通过本文都对高尿酸血症有了一定的了解，所以当你体检发现尿酸增高的时候不要过于惊慌，可以进一步到医院检查，来确定治疗方案，我们一定要重视高尿酸血症的预防和治疗。
